# PARTIE A

- **Internet :** Internet est le réseau global dans lequel on va retrouver plusieurs services comme le Web, les mails (SMTP, IMAP), l’échange de fichiers (FTP), etc.

- **Web :** C’est un service d’Internet. Son nom complet est *World Wide Web*, que l’on peut traduire par « large toile mondiale ». On peut reconnaître l’acronyme « www » présent au début d’une adresse web. Le Web est un ensemble de pages reliées les unes aux autres par des liens hypertextes. C’est à ce moment-là que l’image d’une gigantesque toile illustre parfaitement ce principe.

- **Client :** C’est le navigateur qui va permettre d’afficher les pages web demandées.

- **Serveur :** C’est là que sont stockés les différents fichiers qui permettent à un site web de fonctionner.

- **Navigateur :** Il va interpréter ce que renvoie le serveur pour afficher la page web demandée. Le serveur envoie trois langages différents : HTML, CSS et JavaScript.

- **Nom de domaine :** Nom unique qui permet d’identifier et d’accéder à un site internet.

- **Hébergement :** C’est le fait de stocker les différents fichiers qui servent au bon fonctionnement d’un site sur un ordinateur ou serveur.

- **DNS :** Le DNS (*Domain Name System*, ou système de noms de domaine) est un annuaire informatique qui traduit les noms de sites web compréhensibles par l’humain en adresses IP numériques lisibles par les machines.

- **URL :** C’est l’adresse qui permet d’accéder à une ressource comme une page web, une image, un fichier PDF, etc.

- **HTTP :** HTTP (*Hypertext Transfer Protocol*) est un protocole de communication qui permet d’échanger des données entre un client (comme un navigateur web) et un serveur sur le Web.

- **HTTPS :** C’est la version sécurisée du protocole HTTP qui permet d’afficher les sites web dans un navigateur.

- **Requête :** C’est un message envoyé par un navigateur à un serveur pour demander l’affichage d’une page ou l’accès à une ressource. On parle de requête HTTP ou HTTPS.

- **Réponse :** C’est le retour du serveur suite à la requête envoyée par le navigateur.

- **Code de statut :** C’est un code standardisé de la réponse du serveur au navigateur. Il est composé de trois chiffres et divisé en cinq grandes familles (1xx, 2xx, 3xx, 4xx, 5xx).

  **Exemples :** Erreur 404 (*Not Found*) : la page n’existe pas ; erreur 500 (*Internal Server Error*) : la demande est correcte mais le serveur a rencontré une erreur.

- **API :** C’est une passerelle logicielle qui permet à deux applications ou services de communiquer et d’échanger des données entre eux. On peut prendre comme exemple un affichage de la météo sur un site ou encore une carte interactive.

**Réponse erreur 404 :** L’erreur 404 nous dit que la page web est introuvable. Ça veut que le fichier de votre serveur n’a pas été trouvé. Il nous suffit de retrouver le fichier de votre serveur qui génère ce lien pour vérifier ce qui cloche.

**Conclusion :** vérifier l'html et/ou le chemin d'accès à la page web.
